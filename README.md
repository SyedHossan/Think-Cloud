README – Thought Cloud

Thought Cloud is an interactive, map-based web prototype that lets users explore, post, and engage with student “Thought Clouds” from around the world.
The entire system runs in the browser using HTML, CSS, JavaScript, and LocalStorage. No installation, backend, or external setup is required.

⸻

Features

Users can create Thought Clouds by tapping anywhere on the map.
They can browse posts created by other students globally.
Each pin opens a comment drawer where users can read and reply.
Map pop-ups include a mini user profile for quick context.
Reactions and replies are supported through a simulated interaction system.
Pins can be filtered by student type: Prospective, Incoming, Current, or Alumni.
A simple login and signup flow simulates user profiles.
A fixed bottom navigation bar links to Explore, Notifications, Map, Chat, and Profile screens.
A simulated direct-message inbox is included and stored using LocalStorage.

⸻

How to Run

This prototype is fully browser-based.
Open the file named index.html in any modern browser such as Chrome, Safari, Firefox, or Edge.
No installation or server setup is necessary.
If desired, you may launch it using VS Code’s Live Server extension for auto-refresh.

Limitations

There is no real authentication system.
There is no backend database; all data is stored locally in the browser.
Likes, comments, and chat messages only persist on the user’s device.
Multiple users cannot interact in real time.

These limitations meet the assignment requirement of clearly describing prototype boundaries.
